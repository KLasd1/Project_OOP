# Проект: Веб-сервис «Умный кино-дневник»

## 📁 Что входит в проект:
* **tmdb_5000_credits.csv** — исходный каталог фильмов, скачанный с [Kaggle](https://www.kaggle.com/datasets/akshaydattatraykhare/movies-dataset?resource=download).
* **project.py** — скрипт на Python, который берёт фильмы из каталога и генерирует случайную историю просмотров.
* **user_history.csv** — готовый сгенерированный датасет с историей одного пользователя (содержит 500 оценённых фильмов с датами просмотров).

## 💻 Как работает скрипт project.py:
1. Загружает базу фильмов из CSV-файла.
2. Случайным образом выбирает 500 фильмов.
3. Каждому фильму проставляет оценку от 1 до 10 и случайную дату просмотра за последние полгода.
4. Сохраняет результат в итоговый файл `user_history.csv`.
